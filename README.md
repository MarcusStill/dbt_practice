# dbt Practice: Data Transformations, Macros & Testing

**Практический проект по dbt.**  
Репозиторий демонстрирует мои навыки в создании трансформаций данных, написании макросов, тестировании моделей и работе со снапшотами.

## 🎯 Что я умею в dbt (доказано кодом)

| Навык | Что реализовано | Где смотреть |
|-------|----------------|--------------|
| **Модели данных** | staging, intermediate, core модели с документированием | [`models/`](models) |
| **Макросы** | Подсчёт зависимостей модели, логика переиспользования | [`macros/`](macros) |
| **Тестирование** | Уникальность, not-null, пользовательские тесты | [`tests/`](tests) |
| **Снапшоты** | Отслеживание изменений в SCD Type 2 | [`snapshots/`](snapshots) |
| **Seeds (CSV)** | Загрузка статических справочников | [`seeds/`](seeds) |
| **Analyses** | Аналитические запросы для исследования данных | [`analyses/`](analyses) |
| **Пакеты** | Использование `automate_dv` (Data Vault автоматизация) | [`packages.yml`](packages.yml) |
| **Селекторы** | Поиск всех инкрементальных моделей | [`selectors.yml`](selectors.yml) |
| **Документация** | Описание моделей, столбцов, линий происхождения | `dbt docs generate` |

## 📁 Структура проекта

| Раздел | Содержание |
|--------|-----------|
| [`models/`](models) | Staging, intermediate, core модели (авиаперевозки) |
| [`macros/`](macros) | Переиспользуемая SQL-логика |
| [`tests/`](tests) | Generic и singular тесты |
| [`snapshots/`](snapshots) | SCD Type 2 отслеживание изменений |
| [`seeds/`](seeds) | CSV-справочники |
| [`analyses/`](analyses) | Исследовательские запросы |
| [`sql_scripts/`](sql_scripts) | Вспомогательные скрипты |
